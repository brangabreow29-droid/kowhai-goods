Frequently Asked Questions

What is an Obsidian second brain template?

An Obsidian second brain template is a pre-built vault — a ready-made folder structure, starter notes, and templates you open directly in Obsidian instead of building from a blank app. A good one includes PARA folders (Projects, Areas, Resources, Archive), a daily note template, a weekly review template, Maps of Content that link the system together, and an inbox for fast capture. Is Obsidian free to use for a second brain?

Yes. Obsidian is free for personal use on Windows, Mac, Linux, iOS, and Android, and the free core app includes everything a second brain needs: local Markdown files, bidirectional [[links]], the graph view, daily notes, and templates. Paid add-ons like Obsidian Sync and Publish are conveniences, not requirements — you can sync notes free with any cloud drive, and no subscription is needed to run a complete second brain system.

What is the PARA method in Obsidian?

PARA is a note-organization system with four buckets: Projects (short-term efforts with an outcome and deadline), Areas (ongoing responsibilities with a standard to maintain, like health or finances), Resources (topics you care about that aren't active), and Archive (everything inactive from the other three). You organize notes by actionability — when you'll need them — not by topic. A note about negotiation might sit in Resources for months, then move to a Project folder the week a deal closes. PARA was popularized by Tiago Forte and maps directly to four Obsidian folders.

What should a good second brain template include?

Five things: (1) a capture inbox that everything lands in first, (2) PARA folders so notes are filed by actionability, (3) a daily note and weekly review template that make the habit sustainable, (4) Maps of Content — index notes that link related notes together, and (5) some form of the Distill and Express steps: prompts or workflows that turn accumulated notes into summaries, connections, and publishable output. Most templates stop at folder structure; the leverage is in what helps you actually use the notes.

Obsidian or Notion for a second brain?

Obsidian is better for a second brain if you want local plain-text files you own forever, fast bidirectional linking, and zero subscription. Notion is better if you want databases, collaborative docs, and browser-first access. The trade-off: Obsidian notes are Markdown files on your own disk that open in any text editor and back up with any tool; Notion notes live in a cloud database you access through Notion. For personal knowledge you expect to keep for years, local files with no lock-in win — which is why most second-brain systems are built in Obsidian.

How long does it take to set up a second brain in Obsidian?

Step 1. The Five Parts of a Working Obsidian Second Brain Template

Whether you build it yourself or start from a pre-built vault, these are the non-negotiables:

  1. An Inbox that tolerates mess. One folder, zero guilt. Capture speed beats capture tidiness every time — a messy note in the inbox is worth more than a perfect idea you never wrote down.
  2. PARA folders. Projects (outcome + deadline), Areas (ongoing standard), Resources (topics), Archive (inactive, never deleted — it's your institutional memory).
  3. A daily note template. Today's one important thing, next actions, captures. Same shape every day so the habit has no friction.
  4. A weekly review template. Inbox empty → look back → look ahead → system check. Twenty-five minutes, every Friday. This is the single component that separates systems that live from systems that die in month two.
  5. Maps of Content (MOCs). Index notes per folder — a Projects MOC listing active work, a Resources MOC listing topic clusters. They're the difference between a pile of files and a system you navigate.

Step 2. Build It Yourself in 15 Minutes (the Free Path)

If you'd rather build than download, here's the minimal version — Obsibrain's setup guide pegs this basic structure at about fifteen minutes:

  1. Install Obsidian (free) and create a vault.
  2. Create five folders: 00-Inbox, 01-Projects, 02-Areas, 03-Resources, 04-Archive.
  3. Enable the core Templates plugin and point it at a Templates folder.
  4. Write three templates: a daily note, a weekly review, and a project note (outcome, next action, milestones).
  5. Create one Dashboard note linking to all four folders, and pin it.
  6. Capture your first five notes into the inbox — today, not "when the system is finished."

Resist installing twenty plugins on day one. Plugins solve friction you haven't felt yet; the habit is the asset. Add Dataview or Templater only when a specific, recurring annoyance demands it.

The Five Mistakes That Kill Second Brains

  • Organizing before capturing. A week spent on folder taxonomies is a week of zero captured knowledge. Capture first; the structure earns itself.
  • Topic-based folders. "Marketing," "Health," "Ideas" — topic filing dies because notes are needed by when, not by theme. PARA files by actionability instead.
  • No express step. Notes that never become anything are trivia storage. The system pays off when a cluster of notes becomes an article, a decision, or a project plan.
  • Deleting the archive. Finished projects are case studies. "What did I decide about X, six months ago?" lives in your Archive — keep it searchable.
  • Switching tools. The third migration to a "better" app resets the only asset that matters: months of captured material and the habit around it.
